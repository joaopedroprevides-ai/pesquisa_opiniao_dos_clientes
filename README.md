# Pesquisa de Opinião - TudoWeb

## Sobre o projeto

Este projeto foi desenvolvido em Python para realizar uma pesquisa de opinião com os clientes da empresa fictícia TudoWeb.

O objetivo do programa é coletar informações dos entrevistados e verificar o grau de satisfação em relação ao atendimento prestado.

## Funcionamento

Para cada entrevistado, o programa solicita:

- Nome
- Idade
- Opinião sobre o atendimento

As opções disponíveis são:

1 - EXCELENTE  
2 - BOM  
3 - RUIM  

O programa utiliza uma estrutura de repetição para realizar a pesquisa com os entrevistados e estruturas de decisão para verificar cada resposta.

Ao final da pesquisa, são exibidas:

- Quantidade de respostas EXCELENTE
- Quantidade de respostas RUIM

## Conceitos de Python utilizados

Durante o desenvolvimento foram utilizados:

- Variáveis
- `input()` para entrada de dados
- `print()` para exibição de informações
- `int()` para conversão de valores
- Estrutura de repetição `for`
- Estruturas de decisão `if`, `elif` e `else`
- Contadores

## Testes

Inicialmente, o programa foi testado com 10 entrevistados para verificar se a coleta das informações e a contagem das respostas estavam funcionando corretamente.

Após a validação, a versão final foi configurada para realizar a pesquisa com 50 entrevistados.

## Como executar

1. Tenha o Python instalado no computador.
2. Abra o projeto no Visual Studio Code.
3. Abra o arquivo `app.py`.
4. Execute o programa.
5. Digite os dados solicitados no terminal.
6. Ao final, confira o resultado da pesquisa.

Este projeto tem como objetivo praticar a implementação de algoritmos, estruturas de repetição, estruturas de decisão, entrada de dados e utilização da linguagem Python em um ambiente de desenvolvimento.
